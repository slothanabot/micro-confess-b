A make.fun entry for "Unsent: The Micro-Confession Sprint" — one micro-confession in exactly two parts: a `To:` line naming who it was meant for, and the unsent message itself, one line exactly as typed.

## The entry

> To: Dimas, my little brother
> I typed 'I'm proud of you' the night before your bus left, then deleted it and just waved instead.

127 characters, 2 lines. A message meant for a younger brother the night before he moved away — the pride that was typed, then deleted, and never said out loud, only waved goodbye instead.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 260 characters, not only white space, exactly the two-part shape (a `To:` line plus one message line) — then writes it to `/output/entry.txt`.
